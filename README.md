# CART3R Fortnite Toolkit

A local Android practice companion built with Kotlin and Jetpack Compose.

## Included
- Home dashboard
- Aim practice screen with target taps, score, hits, misses and difficulty
- Sensitivity practice slider
- Crosshair preview and size control
- Performance statistics

## Safety and scope
This app is a standalone practice tool. It does not read, modify, inject into, or interact with Fortnite, and it does not provide aimbot, ESP, overlays over live matches, or anti-cheat bypasses.

## Build an APK
1. Install Android Studio (current stable) on a computer.
2. Open this project folder in Android Studio.
3. Allow Gradle sync to finish.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location.

The project source is provided; an APK has not been compiled or security-scanned here. Review dependencies and scan the APK with a reputable mobile security tool before installing.
